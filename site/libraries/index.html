Libraries

Implementations, measured.

The JavaScript reference implementation and its ports to Rust, Python, Go, Ruby, Java, .NET and PHP. All pass the same -case conformance suite, give identical answers on every version and range in the benchmark corpus, and are timed against the libraries they replace on real versions and ranges from the npm registry.

At a glance

Conformance counts the cases each library passes in the shared suite (libraries that do not expose a desugared range are scored on the 413 cases that do not need one); speed is the range of speed-ups over the compared library across the operations below. Each language is measured in its own runtime on the same machine, so compare numbers within a language, not across languages. Method and raw results: benchmarks/.
