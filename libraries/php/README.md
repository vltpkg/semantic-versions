# semantic-versions for PHP

The PHP implementation of [**Semantic Versions**](https://semver.xyz): parse,
validate, compare and range-match version numbers, with builds that participate
in precedence.

It is a port of the JavaScript reference implementation
([`semantic-versions`](https://www.npmjs.com/package/semantic-versions) on npm)
and behaves identically: both pass the same
[conformance suite](https://github.com/vltpkg/semantic-versions/tree/main/conformance),
and they agree on every version, range and resolution in the benchmark corpus.
PHP 8.1+, no dependencies.

## Install

```sh
composer require vltpkg/semantic-versions
```

## Usage

```php
use Vlt\SemanticVersions\Range;
use Vlt\SemanticVersions\SemanticVersions as SV;
use Vlt\SemanticVersions\Version;

$v = Version::parse('1.2.3-beta.4+build.7');
// $v->major === 1, $v->prerelease === 'beta.4', $v->build === 'build.7'

// Builds participate in precedence: a build ranks above its plain release.
Version::parse('1.0.0')->compare(Version::parse('1.0.0+build.1')); // -1

SV::satisfies('1.4.0', '^1.2.3');             // true
SV::satisfies('1.0.0-rc.1', '^1.0.0-rc');     // true: pre-release channel
SV::satisfies('1.0.0-beta', '^1.0.0-rc');     // false: a different channel
SV::satisfies('1.4.2+win.x64', '^1.0.0+win'); // true: build channel
SV::validRange('~>1.2');                      // '>=1.2.0 <1.3.0-0'

// Contexts scope a version or range to an identity.
$react = Range::parse('npm:react@^18');
$react->test(Version::parse('npm:react@18.2.0'));      // true
$react->test(Version::parse('composer:react@18.2.0')); // false

SV::maxSatisfying(['1.0.0', '1.9.0', '2.0.0'], '^1'); // '1.9.0'
```

`Version::parse` and `Range::parse` throw `SemanticVersionException`;
`tryParse` returns `null` instead.

## How this differs from `composer/semver` and `z4kn4fein/php-semver`

- **Builds participate in precedence** (`1.0.0 < 1.0.0+build`), and a build on a
  comparator is a [channel filter](https://semver.xyz/spec/#build-channels).
- **Pre-releases are range-driven**: a pre-release on a comparator is a
  [prefix channel](https://semver.xyz/spec/#pre-release-channels) scoped to its
  tuple; `X.Y.Z-*` and `*-*` opt in explicitly.
- **Contexts**: `npm:react@18.2.0`, `npm:@babel/core@^7`.
- **No coercion**: `v1.2.3` and `1.2` are errors.
- **No stability flags or four-part versions**: `1.0.0-rc.1` stays `1.0.0-rc.1` rather than becoming Composer's `1.0.0.0-RC1`, and any pre-release name is allowed.
