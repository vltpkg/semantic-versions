# SemanticVersions for .NET

The C# implementation of [**Semantic Versions**](https://semver.xyz): parse,
validate, compare and range-match version numbers, with builds that participate
in precedence.

It is a port of the JavaScript reference implementation
([`semantic-versions`](https://www.npmjs.com/package/semantic-versions) on npm)
and behaves identically: both pass the same
[conformance suite](https://github.com/vltpkg/semantic-versions/tree/main/conformance),
and they agree on every version, range and resolution in the benchmark corpus.
For .NET 8+, no dependencies, AOT-compatible.

## Install

```sh
dotnet add package SemanticVersions
```

## Usage

```csharp
using SemanticVersions;

var v = SemanticVersion.Parse("1.2.3-beta.4+build.7");
// v.Major == 1, v.Prerelease == "beta.4", v.Build == "build.7"

// Builds participate in precedence: a build ranks above its plain release.
bool above = SemanticVersion.Parse("1.0.0") < SemanticVersion.Parse("1.0.0+build.1"); // true

Versions.Satisfies("1.4.0", "^1.2.3");             // true
Versions.Satisfies("1.0.0-rc.1", "^1.0.0-rc");     // true: pre-release channel
Versions.Satisfies("1.0.0-beta", "^1.0.0-rc");     // false: a different channel
Versions.Satisfies("1.4.2+win.x64", "^1.0.0+win"); // true: build channel
Versions.ValidRange("~>1.2");                      // ">=1.2.0 <2.0.0-0"

// Contexts scope a version or range to an identity.
var react = SemanticRange.Parse("npm:react@^18");
react.Test(SemanticVersion.Parse("npm:react@18.2.0"));   // true
react.Test(SemanticVersion.Parse("nuget:react@18.2.0")); // false

Versions.MaxSatisfying(["1.0.0", "1.9.0", "2.0.0"], "^1"); // "1.9.0"
```

`Parse` throws `SemanticVersionException` (a `FormatException`); `TryParse`
returns `false` instead. `Versions.Sort` is stable.

## How this differs from `Semver` and `SemanticVersioning`

- **Builds participate in precedence** (`1.0.0 < 1.0.0+build`), and a build on a
  comparator is a [channel filter](https://semver.xyz/spec/#build-channels).
- **Pre-releases are range-driven**: a pre-release on a comparator is a
  [prefix channel](https://semver.xyz/spec/#pre-release-channels) scoped to its
  tuple; `X.Y.Z-*` and `*-*` opt in explicitly.
- **Contexts**: `npm:react@18.2.0`, `npm:@babel/core@^7`.
- **No coercion**: `v1.2.3` and `1.2` are errors.
